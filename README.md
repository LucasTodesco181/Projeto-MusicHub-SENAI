## 📌 Sobre o Projeto

O **MusicHub** é uma plataforma de streaming e rede musical desenvolvida para o **SENAI**. O projeto une a nostalgia da cultura pop dos anos 2000 a um ecossistema moderno de navegação, oferecendo widgets retrô interativos (como player de iPod/MP3), customização de perfil e gerenciamento de assinaturas.

---

## ✨ Funcionalidades em Destaque

* 🔐 **Autenticação & Conta:** Páginas dedicadas de Login, Cadastro e Alteração de Senha.
* 🎧 **Widgets Interativos:** Player estético com visual clássico de MP3 / iPod e suporte a dispositivos como AirPods Mini.
* 👤 **Perfil Customizável:** Exibição de bio, seguidores, *Top Artistas do Mês*, *Top Plays*, álbuns favoritos e playlists criadas.
* 💳 **Planos e Assinaturas:** Tela de seleção de planos VIP (Solo, Dupla, Família e Universitário).
* 🎶 **Navegação de Conteúdo:** Páginas detalhadas para Álbuns, Explorar por gêneros (*Sertanejo, Eletrônica, Funk, MPB, Pop*), Clipes e Seção "Direto dos Anos 2000".

---

## 🎨 Layout e Identidade Visual

A interface foi projetada com base nas tendências **Y2K / Frutiger Aero**, utilizando gradientes em tom azul-elétrico sobre fundos escuros e elementos texturizados.

| Elemento | Paleta / Hex |
| :--- | :--- |
| **Fundo Principal** | Dark Obsidian (`#050B14`) |
| **Destaques & Badges** | Electric Blue (`#00D2FF` / `#1D4ED8`) |
| **Texto & Ícones** | Bright Silver (`#E2E8F0`) |
